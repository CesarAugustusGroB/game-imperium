El trato en una línea

Un Decretum de la mano se lanza desde el Hub (pestaña Decreta) por un efecto de Hub instantáneo (boon inmediato) o continuo por N temporadas (tickea en el reloj). Se consume al lanzarse. No entra a Iter Belli. Solo los Decreta cuyo efecto traduce bien al Hub son casteables; el resto queda inerte por ahora.

DóndeHub (pestaña Decreta), no la campaña
EfectoInstantáneo o continuo N temporadas
ContenidoSet chico vivo + resto inerte
ConsumoSingle-use, respeta faction-lock + castCost

Ciclo de vida

Decretum en la mano (castable en Hub) → Lanzar · gasta castCost · removeDecretum → instantáneo: aplica boon ya / continuo: push a activos (N temporadas) → season-tick: aplica + decrementa + expira

El set chico de efectos-Hub vivos

Valores/inclusiones propuestos — ajustables. toHubEffect(decretum) → HubDecretumEffect | null (null = inerte).

Vivos ≈ 10–12 Decreta (grants de oro, sanaciones, supply/annona, cursus); el resto inerte. La arquitectura permite ampliar el set después. Único continuo de esta fase: waive-upkeep (es el único que los datos existentes necesitan).

Arquitectura (Hub puro — no toca Iter Belli)

game items/decretum-hub.ts Nuevo

  • HubDecretumEffect — union del set vivo (grant / heal-army / shop-discount / recruit / waive-upkeep).
  • toHubEffect(d): HubDecretumEffect | null — switch por effect.type; null para deprecados/solo-batalla.
  • isCastableAtHub(d, faction) — faction-lock + tiene efecto-Hub + afford castCost.
  • castDecretumAtHub(id) — gate → aplica instant / push continuo → removeDecretum.

game items/decretum-store.ts Extender

activeDecretumEffects: signal<ActiveDecretumEffect[]> — { decretumId, name, effect, remainingSeasons }.

game progression/season-tick.ts Extender

  • Leer los waive-upkeep activos → upkeep = 0 esa temporada (junto a la reducción de doctrinas que ya se consume acá).
  • Tras el tick: remainingSeasons-- y filtrar los expirados (≤ 0).

ui forum/tabs/DecretaTab.tsx Extender

  • Botón "Lanzar" en el detalle (habilitado si isCastableAtHub; muestra qué hará).
  • Lista de efectos continuos activos con temporadas restantes.
  • Actualizar el hint ("se lanzan en batalla" → "se lanzan en el Hub"). DecretaPanel: badge de activos (opcional).

Por qué encaja

  • Reusa isDecretumCastable (faction-lock), removeDecretum (consumo), addResource/spendResource (boons + castCost), preparedArmy (heal), nextInvestmentDiscount (descuento) — todo ya existe.
  • El sistema continuo-con-duración es nuevo pero mínimo (un signal + tick-down en season-tick), modelado sobre el precedente de doctrinas + expiry.
  • Da un hogar vivo a los Decreta (hoy muertos: se lanzaban en la batalla hex deprecada).
